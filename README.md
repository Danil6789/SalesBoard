# Salesboard — Доска объявлений с авторизацией

Salesboard — это полнофункциональное веб-приложение для размещения объявлений. Проект представляет собой классическую доску объявлений с системой регистрации, JWT-аутентификацией и возможностью создавать, редактировать и удалять объявления.

## О проекте
Pet-проект, созданный для изучения и практической реализации fullstack-разработки. Основная цель — построить чистое, масштабируемое приложение с разделением на бэкенд и фронтенд, используя современные подходы и инструменты.

## 🛠 Стек технологий

### Backend
- **Java 22** — современная версия языка с долгосрочной поддержкой
- **Spring Boot 3** — основа приложения, упрощает конфигурацию и запуск
- **Spring Security** — отвечает за аутентификацию и разграничение доступа
- **Spring Data JPA** — для работы с базой данных через ORM
- **JWT** — для безопасной аутентификации без сохранения сессий
- **MapStruct** — маппинг между сущностями и DTO (избавляет от рутинного кода)
- **Maven** — сборка проекта и управление зависимостями

**Архитектура:** многослойная структура (контроллеры → сервисы → репозитории) с четким разделением ответственности и использование



### Frontend
- **Angular** — современный фреймворк для построения SPA
- **TypeScript** — типизированный JavaScript для надежности кода
- **HTTP Interceptors** — для автоматического добавления JWT-токена в запросы
- **RxJS** — для работы с асинхронными операциями

## ✨ Функциональность

### Что уже реализовано:
- ✅ Регистрация и вход в систему (JWT-аутентификация)
- ✅ Просмотр списка объявлений
- ✅ Создание нового объявления
- ✅ Редактирование своих объявлений
- ✅ Удаление своих объявлений
- ✅ Личный кабинет пользователя
- ✅ Защита маршрутов на фронтенде (только для авторизованных)
- ✅ Добавление токена в заголовки запросов (Interceptor)
